# RES-Slim v0.3.3

Fresh branding.

- New extension icon set: minimalist "RS" monogram on a dark charcoal circle with a Reddit-orange accent bar. Replaces the upstream RES UFO design.
- Toolbar action icon (`css-on` / `css-off`) redesigned to match — full-color "R" + orange bar when active, desaturated gray when inactive.
- Beta-flavor icons regenerated with a teal accent and a β badge in the corner.
- New `build/generate-icons.py` — Pillow-based icon generator. Run `python build/generate-icons.py` from the repo root to regenerate the full icon family at every referenced size.

No module / behavior changes.
