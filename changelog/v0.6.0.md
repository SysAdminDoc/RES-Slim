# v0.6.0 — 2026-05-19

Phase 5 (Core Engine and Capture Contracts) and Phase 6 (Settings Panel and
Dark/OLED Design System) are both shipped under one version bump. v0.5.0 work
landed in prior commits without a version bump; v0.6.0 consolidates both.

## Phase 5 — Core engine and capture contracts

- Reversible feature engine with `init()`/`destroy()` lifecycle.
- Old-Reddit selector map, `findElement`/`waitForElement` helpers, and
  selector-contract tests against the frontpage + thread MHTML fixtures.
- Settings schema, defaults, migration helpers, and contract tests.
- TrustedTypes-aware HTML helpers (`trustedHtml`).
- Dark-only toast host and local error log panel with pointer-safe
  inactive states.
- Document-start anti-FOUC class for OLED / dark.

## Phase 6 — Settings console design system

- **OLED is now the default theme.** All theme presets (oled, graphite,
  midnight, forest, ember) live in `lib/core/theme/settingsThemePresets.js`,
  the single source of truth for the template, controller, and tests.
- **Density toggle** (`comfortable` / `dense`) persists to `localStorage`
  and tightens header/sidebar/workspace padding.
- **Reduce-motion override** persists to `localStorage` and suppresses every
  transition, animation, and hover-lift inside the console. The OS
  `prefers-reduced-motion: reduce` media query also triggers the same
  suppression unless the user explicitly opts back in.
- **Branded thin scrollbar** scoped to the console container so the accent
  threads through scroll regions.
- **JSON import/export** via header buttons. Export downloads a snapshot
  blob with app/format/version/exportedAt metadata. Import opens a file
  picker, applies the snapshot, and reloads. The snapshot stores raw
  `storage.getAll()` output, so unknown future module IDs and option keys
  round-trip without being filtered out.
- **Toast feedback** for every preference change: theme, density, motion,
  module enable/disable, save commit, discard staged, plus import/export
  success and failure.
- **WCAG AA contrast contract.** New `tests/unit/settings-console-contrast.test.mjs`
  parses each theme's SCSS token block and computes WCAG 2.x relative
  luminance contrast ratios for body text, muted text, and accent against
  the bg / panel / panel-raised / field surfaces, plus the flattened
  accent-soft overlay. All five themes pass AA.
