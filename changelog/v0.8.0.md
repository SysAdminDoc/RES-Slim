# v0.8.0 — 2026-05-19

Phase 8: Navigation and Comment Workflow. Seven new modules, one
shared rate-limiter utility, 138 passing tests, no manifest
permission changes.

## New modules

- **continueThreadInline** — replace "continue this thread →" with an
  inline fetch+splice into the existing nested listing. Honours
  modifier keys (ctrl/middle still open a new tab).
- **scrollRestore** — remember `window.scrollY` per `location.pathname`
  in a localStorage LRU (default 200 entries). Restores at
  `contentStart`; bails if the URL has a hash so permalink jumps win.
- **threadMinimap** — fixed 16px depth/score heatmap rail on comment
  pages with a scroll-tracked viewport overlay and click-to-jump.
  Pointer-events scoped so the rest of the page still scrolls.
- **searchFilterPersist** — remember sort + time-window across
  /search and /r/<sub>/search. Replays at `beforeLoad`; captures both
  from the URL and from form submissions.
- **searchDispatcher** — small `<select>` next to the header search
  input routing queries to Reddit, the current subreddit, Google
  `site:reddit.com`, DuckDuckGo `site:reddit.com`, or custom
  user-defined targets.
- **topCommentsPreview** — inline "preview top" link per listing post
  that fetches the top N comments via `.json?sort=top&depth=1` and
  splices them under the post. Cached + rate-limited.
- **autoRefreshComments** — opt-in poll loop on /comments/ pages with
  exponential backoff (start 30s, cap 300s, doubles on empty polls,
  resets on success). Network failures slow without stopping.

## New utilities

- **lib/utils/rateLimiter.js** — token-bucket with configurable
  tokens / refillMs / maxConcurrent. Shared between
  topCommentsPreview and autoRefreshComments.

## Test coverage

138 passing across `tests/unit/`. Seven new contract files this
phase; the rate limiter exercise includes a runtime queue-ordering
test through `flow-remove-types`.

## Acceptance criteria

- [x] MutationObserver processes added nodes only (threadMinimap +
      continueThreadInline both go through `watchForThings` or a
      target-scoped observer; nothing scans the whole tree on
      mutation).
- [x] API calls are cached and rate-limited (shared rateLimiter +
      per-permalink cache in topCommentsPreview).
- [x] Continue-thread loader can be destroyed and restores original
      link (dataset reset on failure; the original `<a>` is reused).
- [x] Thread minimap does not block comment scrolling (fixed
      container is `pointer-events: none`; only the rail/stripes are
      `auto`).
