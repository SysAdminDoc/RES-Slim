# v0.7.0 — 2026-05-19

Phase 7: Privacy, Redirect, and Anti-Promo Suite. Six new modules,
ninety-five passing tests, no new external network calls by default.

## New modules

- **removePromoted** — hides `.thing.link.promoted` and
  `.thing.link[data-promoted="true"]` posts from feed pages, with a
  per-page-load count badge in `#header-bottom-right`. Defaults on.
- **outboundCleanser** — strips Reddit's `out.reddit.com` tracker
  wrappers and common UTM / ref / share-id query parameters from
  anchors on hover, copy, contextmenu, focus, and click. Mutation
  observer re-sweeps anchors added by infiniteScroll. Defaults on.
- **eventTrackingSabotage** — page-world script wraps
  `navigator.sendBeacon`, `window.fetch`, and `XMLHttpRequest` for
  Reddit's first-party telemetry hosts and analytics paths (`/api/event`,
  `/api/v1/page_view`, `/api/v1/clk`). Optional `logBlocked` switch
  reports drops to the console. Defaults on, silent.
- **frictionRemovers** — four independent switches: auto-confirm
  `/over18` and `/quarantine` gates, hide "use new Reddit" banner, hide
  "open in app" prompt. All default on.
- **oldRedditRedirect** — opt-in `www.reddit.com → old.reddit.com`
  redirect at `document_start` (off by default), plus an
  always-on (configurable) `old / www / sh` host toggle pill injected
  into the userbar. Active host is marked.
- **hideUsername** — replaces the logged-in user's name in the userbar
  and across `.author` links with a configurable placeholder (default
  `[me]`). Optional karma masking. Useful for streamers and screen
  shares. Defaults on (no-ops when logged out).
