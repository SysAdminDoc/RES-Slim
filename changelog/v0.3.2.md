# RES-Slim v0.3.2

Settings console polish + two new appearance modules + stability fixes across the v0.3.0 ecosystem ports.

## New modules
- **classicFavicon** — restores the original reddit alien favicon in the browser tab. Inspired by chairmanbrando's "Reddit: Old Favicon" userscript.
- **disableSubredditStyles** — globally strips `applied_subreddit_stylesheet` link elements so every sub renders with default old.reddit chrome. Adapted from the GreasyFork "Subreddit style remover" userscript.

## Module stability fixes
- `commentHighlights`, `commentTools`, `downloadButtons`, `fixImageLinks`, `fixProcessingImg`, `infiniteScroll`, `markAllRead`, `nextTopComment`, `nightMode`, `reddEye`, `restoreSubCounts`, `userProfileSearch`, `viewDeleted`, `autoExpand`, `absoluteTimestamps`, `menu`, `version`, `search` — small correctness/style refinements from a review pass over the v0.3.0 ports.

## Settings console
- `lib/options/options.scss` — substantial restyling pass (~1300 lines updated).
- `lib/options/settingsConsole.js`, `lib/options/templates.js`, `lib/utils/createElement.js` — template + helper refinements.
- `locales/index.js`, `locales/locales/en.json` — 12 new locale keys for the new modules.
