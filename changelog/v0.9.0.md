# v0.9.0 — 2026-05-19

Phase 9: Theming and Layout Superset. Two new modules, 144 passing
tests.

## New modules

- **layoutTweaks** — single module with seven body-class-gated CSS
  toggles: full-width content, hide right sidebar, post numbering,
  hide award badges, hide user flair, hide post link flair, hide
  avatars. All controlled by `body.rsm-layout-*` classes so the
  module's `destroy()` is a no-op beyond removing the classes.
- **commentDepthColors** — paint each `.thing.comment` left border
  with an HSL stripe whose hue rotates by comment depth. Saturation
  and max-depth are configurable; the rule set is computed once and
  scoped behind `body.rsm-depth-colors`.

## Deferred (with reason)

- **Multi-column feed** — needs CSS grid restructuring of
  `#siteTable.linklisting` plus thumbnail-size tuning. Scheduled for
  v0.10 once the filter builder lands so column eviction is
  observable in one pass.
- **OP/admin/mod/friend highlight refresh** — existing
  `commentHighlights` module already covers the OP path; admin / mod
  / friend lanes will be folded into the v0.10 user-tagger work.
- **Custom subreddit style override** — `disableSubredditStyles`
  already covers the binary kill switch; the per-sub allow/deny list
  is scheduled for v0.10 alongside the filter builder.

## Acceptance criteria

- [x] All layout toggles are per-page and reversible (toggling the
      option flips the body class without reload).
- [x] No nested cards inside cards (layoutTweaks injects flat,
      single-purpose rules with no card wrappers).
- [x] No fully rounded / pill UI surfaces (test asserts no
      `border-radius: 999px` or `50%` in the injected CSS).
- [x] Subreddit custom CSS cannot permanently hide settings access
      (handled by `disableSubredditStyles`; layoutTweaks rules are
      `!important` so subreddit themes cannot override them).
