# RES-Slim v0.2.0

- Gear icon now opens the settings console directly (no dropdown menu).
- Removed the `About RES` and `Search RES Settings` module entries from the settings sidebar. The in-console search box still works; the `search` module is kept loaded but hidden.
- Removed the `troubleshooter` module.
- Restored the RES **Night Mode** (dark theme). Minimal version: one toggle in `appearanceCategory` → `nightModeOn` (default on). Automatic sunrise/sunset, subreddit-whitelist, and custom-toggle integrations from upstream are omitted.
- Settings console now lands on Night Mode by default.
