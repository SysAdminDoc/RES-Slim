# RES-Slim v0.3.1

Settings console UX improvements (authored externally, merged in).

- `lib/core/modules/index.js`, `lib/core/modules/modules.js` — module listing / state plumbing cleanup.
- `lib/core/options/stage.js` — staging-layer refinements for option edits.
- `lib/modules/search.js` — tightened the settings search input + result rendering.
- `lib/options/settingsConsole.js` — new `getModuleEnabled()` helper, module enable/disable toggle with permission prompts, disabled-module scrim overlay, category-panel navigation tweaks.
- `lib/options/options.scss` — substantial restyling of the console.
- `lib/options/templates.js` — updated console templates to match the new scss.
- `lib/utils/createElement.js` — helper additions for the new toggles.
- `package.json` / `yarn.lock` — dev dependency touch-ups.

Module count unchanged (43). No behavioral changes to comment/media modules.
