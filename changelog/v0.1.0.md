# RES-Slim v0.1.0

Initial fork from Reddit Enhancement Suite v5.24.8.

Trimmed to comment tweaks and media expandos for old.reddit.com only.

- Removed: browsing/nav helpers, filters/user tagging, subreddit/profile tools, submit/mod helpers, style tweaks, messaging, cloud backup, search, about/contribute/announcements/onboarding, FUNDING metadata.
- Kept: hideChildComments, commentNavigator, commentPreview, commentTools, commentQuickCollapse, commentSortBy, commentStyle, commentDepth, commentHidePersistor, saveComments, hover, showParent, readComments, newCommentCount, spoilerTags, noParticipation, sourceSnudown, showImages (all 87 host handlers), plus required infra (menu, notifications, settingsNavigation, selectedEntry, version, requestPermissions, troubleshooter).
- Zero analytics / telemetry / ads (confirmed against upstream audit).
